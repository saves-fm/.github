# Getting Support

## Questions and ideas

Please don't open an issue for questions. Issues are for bugs and planned work.

For questions, ideas, or general conversation, use [GitHub Discussions](https://github.com/saves-fm/saves/discussions).

## Bug reports and feature requests

[Open an issue](https://github.com/saves-fm/saves/issues/new/choose) on the saves repo. See [CONTRIBUTING.md](CONTRIBUTING.md) for what to include.

## Security vulnerabilities

See [SECURITY.md](SECURITY.md). Please do not report vulnerabilities in public issues.
