# Security Policy

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report it privately through GitHub: go to the [Security tab of the saves repo](https://github.com/saves-fm/saves/security) and choose **Report a vulnerability**. Include a description, steps to reproduce, and any relevant context. We will acknowledge your report within 72 hours and aim to release a fix within 14 days for confirmed vulnerabilities.

saves.fm stores email addresses, passkeys, linked RetroAchievements accounts and unlock history. Reports that touch account takeover, RA account linking, or exposing private or Untracked profiles are treated as the highest priority.

We will credit researchers who report valid vulnerabilities, unless you prefer to remain anonymous.

## Supported versions

saves.fm is in the planning stage and nothing is deployed yet. Once the web app launches (v1.0.0), the live service and the latest release are supported.
